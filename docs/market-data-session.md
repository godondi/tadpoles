# Fauxnance candles and internal booking sessions

The backend candle DTO omits null fields. Synthetic daily bars can therefore arrive without `volume`. The chart accepts missing or null volume as unavailable, normalizes it to null for display/deduplication, and continues to validate dates, positive OHLC values and their high/low relationships.

Fauxnance can return fresh quotes with `marketState: "unknown"` during core trading hours. For internally booked orders, `TradingSession` accepts that explicit state only during a verified scheduled core session for the configured NYSE, NYSE Arca or NASDAQ venue. It uses `America/New_York` (including DST), 09:30 inclusive through 16:00 exclusive, weekends, full holidays and 13:00 early closes. The checked-in calendar covers **2026 only**; extend and verify it before another year. Unsupported venues/years and absent or unrecognized states fail closed. Explicit provider closed/pre/post states always take precedence.

The published schedules are [NYSE hours and calendars](https://www.nyse.com/trade/hours-calendars) and [Nasdaq's 2026 trading calendar](https://www.nasdaqtrader.com/trader.aspx?id=Calendar). This is a scheduled-session fallback for internal bookings, not a live exchange-status feed. Operations must disable trading for unscheduled closures or halts that the provider does not report.

The provider's original `unknown` state stays in quote evidence; successful evaluation reasons identify use of the scheduled session. Preview, admission and worker execution all use the same rule. All price, currency, freshness, metadata and resource checks still apply, including the configured maximum quote age. A cached provider quote may report `stale: false` yet fail its timestamp check; the application must not treat that flag as permission to use an expired price.

The internal demo catalog defaults to a 1200-second maximum quote age to accommodate the reported twenty-minute provider refresh cadence. Operations can set a stricter age per instrument; the editor/API accept 1–1200 seconds. Existing policies are preserved on startup and must be changed through Operations, retaining their revision and audit trail. Quotes marked stale, older than the selected age, or future-dated beyond the clock-skew allowance remain ineligible.

If Fauxnance explicitly returns `meta.stale: true`, order checks return `QUOTE_STALE` with a message explaining that the provider must update before the order can be reviewed again. This applies even within the configured age allowance. Absent freshness, missing metadata timestamps, unsupported spread sources and blank quote sources have separate explanatory messages under `QUOTE_METADATA`. Refreshing the application requests another provider observation; it cannot force the upstream cache to refresh.
